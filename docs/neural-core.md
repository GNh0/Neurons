# 목표: 뉴런과 시냅스가 판단과 학습을 담당하는 시스템

2026-09-13 · v0.3 실험 구현과 남은 핵심 개발 기준.

사용자가 원하는 것은 LLM이 질문과 검색을 대신 수행하는 것에 그치지 않습니다. 감각·경험을 받은 신경 회로가 내부 상태를 유지하고 행동을 선택하며, 결과에 따라 시냅스를 바꾸고 다음 행동을 달리하는 시스템입니다. LLM은 입력·출력의 언어 변환과 자료 해설을 담당하는 보조 모듈로 둡니다.

## 현재 실제 동작

- MaleCNS 166,700개 뉴런과 25,582,938개 가중 연결에서 LIF 신호 전달을 계산합니다. 124,177,617개 접촉 수를 연결 가중치에 합산했습니다.
- 원본 회로의 연결 가중치는 고정입니다. 개체별 감각 인코딩과 실제 LIF 발화에서 50개 특징을 읽고, 별도로 추가한 12개 확률적 행동 뉴런의 600개 가중치를 학습합니다. 모든 MaleCNS 시냅스를 훈련하거나 해부학적 운동 출력을 그대로 재현한 모델이 아닙니다.
- 자료 탐구의 자연어 질문·검색어·요약은 로컬 LLM이 만듭니다. 개체의 목적과 최근 관측을 참고합니다. 출처가 저장되면 자기 경험 중 복습할 범주를 고르도록 하고, 기록된 실제 보상으로 동일한 행동 가중치를 갱신합니다. 이 과정이 LLM 없이 자연어 의문을 생성하는 신경망을 뜻하지 않습니다.
- 화면의 발광, 발화량, 연결 개수, 자연스러운 대화만으로 사고나 발전을 입증할 수 없습니다.

## 핵심 실행 경로

오픈월드의 방향별 먹이 냄새·이동 가능성·방문 정보, 에너지·상수, 주변 사물·재료·동료·사물 지식·소지품과 생리 욕구를 총 42개 감각 채널로 만듭니다. 168개 감각 세포에 인위적으로 배정하며 채널당 4개 세포에 확률적 전류를 보냅니다. 매 행동마다 개체의 전체 LIF 그래프를 10 ms 계산합니다. 42개 감각군과 8개 전체 신경 집단에서 발화를 측정합니다. 방향별 네 채널의 평균을 빼 공통 발화를 제거하며 비방향 입력은 작은 비율로 조절합니다. 특징 순서는 기존 14감각+8집단 다음에 신규 28감각을 붙여 저장 호환성을 유지합니다. 세계 좌표나 거리 자체가 행동 선택기로 바로 전달되지는 않습니다. 방문과 사물 기억은 외부의 개체별 기록이며 관련 감각을 만드는 데 사용됩니다.

측정 특징 x와 학습 행렬 W를 곱한 전위에서 exp(xW)에 비례하는 발화율을 만들고, 지수분포 경쟁에서 먼저 발화한 행동을 선택합니다. 이는 escape-noise 방식의 실험 readout이며 원본 LIF와 다른 모델입니다. 실제 보상 r, 이동 평균 b, 선택 발화 y, 기대 발화확률 p를 이용해 W += 학습률 × clip(r−b,−3,3) × outer(x,y−p)를 적용하고 가중치를 −4~4로 제한합니다. 학습률 유전 특성은 0.04~0.18 범위이며 초기 기준값은 0.12입니다. b는 0.03 비율로 갱신합니다. 유충은 몸체에서 허용한 행동만 선택하고 알·번데기는 발달합니다. 보상 학습을 끄면 W는 유지되고 행동은 계속됩니다. 생물학적 STDP를 구현했다고 주장하지 않습니다.

공통 보상은 새로운 방문·사물 조사, 실제 재료 수집·제작·전달·회복의 결과와 충돌·굶주림·갈증·손상에서 계산합니다. 선택 목적에 따라 먹이 거리 변화, 새 지역, 교류·제작에 추가 보상이 붙습니다. 정확한 보상식은 `neurons/open_world.py`의 `act`에 공개되어 있습니다. 배고픔·갈증·피로·안전·호기심·교류·번식 욕구, 성장과 사망은 [별도 생애 규칙](living-world.md)으로 계산합니다. 이 수치들은 실험 조건이며 생물의 주관적 욕구나 실제 초파리의 생리 파라미터를 재현한 것이 아닙니다.

LLM 자료 보조는 보상이나 행동을 만들어 넣지 않습니다. 출처가 있는 기억 ID와 복습 범주를 검증한 뒤, 최대 최근 200개 실제 경험 중 해당하는 16개를 다시 학습합니다. 과거 행동 확률에 대한 중요도 비율은 최대 2로 제한합니다. 요약이 잘못됐을 수 있으므로 복습 제안은 독립 검증 전으로 표시합니다. LLM 보조가 실제 성능에 주는 이득은 별도 비교 실험이 필요합니다.

환경·감각 → 입력 인코딩 → 신경 활동과 유지되는 내부 상태 → 신경 출력에 따른 행동 선택 → 환경의 결과 → 예측 오차·보상 → 시냅스 변화 → 다음 행동.

신경 회로에서 행동이 선택되는 경로에 LLM의 답변을 정답처럼 주입하지 않습니다. 첫 검증에서는 LLM을 꺼도 감각 반응, 행동 선택, 학습, 저장과 재실행이 동작해야 합니다. 자연어 의문 생성·인터넷 검색까지 신경 회로가 주도하려면 별도의 개념 표현, 기억, 행동 공간과 과제 학습을 검증해야 합니다.

| 필요한 구성 | 구현·검증 기준 |
| --- | --- |
| 실험 신경 회로 | 보존 원본에서 재현 가능한 실험 상태를 만들고 바뀐 시냅스를 실제 신호 계산에 사용 |
| 가소성 | 사전·사후 뉴런 활동, 적격 흔적, 보상 또는 예측 오차가 어떤 연결을 바꿨는지 기록 |
| 안정성 | 가중치 한도·항상성·비정상 발화 제어, 되돌릴 체크포인트 |
| 감각·행동 연결 | 입력 뉴런과 출력 뉴런의 역할·단위·가정 공개, 실제 해부학적 근거와 인위적 할당 구분 |
| 내부 동기 | 낯선 상태·예측 실패를 수치로 정의하고 탐색 행동의 결과와 연결 |
| 경험 기억 | 학습한 회로 상태를 저장하고 재실행 후 같은 조건에서 재현 |
| 모니터 | 입력, 발화, 선택 행동, 결과, 시냅스 변화와 근거를 관찰 가능한 사건으로 표시 |

첫 과제는 작은 감각·행동 환경에서 검증합니다. 먹이 도달률 같은 사전 정의된 성과를 여러 초기 조건에서 측정하고, 학습 전 회로·학습을 끈 회로·학습 후 회로를 같은 미학습 조건에 비교합니다. 가중치만 바뀌고 성과가 개선되지 않았다면 발전으로 보고하지 않습니다.

이는 개발·연구 방향입니다. 공개 연결지도만으로 인간 수준의 사고, 자발적인 자연어 질문, 의식이 생긴다는 보장은 없습니다. 작은 행동 과제의 성공을 일반적인 사고 능력의 완성으로 확대하지 않습니다.

참고: [Shiu et al., Nature 2024](https://www.nature.com/articles/s41586-024-07763-9)의 연결지도 기반 감각·운동 계산 모델과 [Legenstein et al., PLoS Computational Biology 2008](https://doi.org/10.1371/journal.pcbi.1000180)의 보상 조절 가소성 연구는 출발점이며, 이 프로젝트가 해당 학습 결과를 재현했다는 뜻은 아닙니다.
