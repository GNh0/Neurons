# 목표: 뉴런과 시냅스가 판단과 학습을 담당하는 시스템

2026-09-13 사용자 요구 정정. 현재 버전의 구현 완료를 뜻하지 않는 핵심 개발 기준입니다.

사용자가 원하는 것은 LLM이 질문과 검색을 대신 수행하는 것에 그치지 않습니다. 감각·경험을 받은 신경 회로가 내부 상태를 유지하고 행동을 선택하며, 결과에 따라 시냅스를 바꾸고 다음 행동을 달리하는 시스템입니다. LLM은 입력·출력의 언어 변환과 자료 해설을 담당하는 보조 모듈로 둡니다.

## 현재 실제 동작

- MaleCNS 166,700개 뉴런과 25,582,938개 가중 연결에서 LIF 신호 전달을 계산합니다. 124,177,617개 접촉 수를 연결 가중치에 합산했습니다.
- 해당 회로의 연결 가중치는 현재 고정되어 있습니다. 개별 접촉의 가소성, 보상에 따른 회로 학습, 신경 출력에 따른 행동 선택은 구현되어 있지 않습니다.
- 자료 탐구는 로컬 LLM이 계획하고 요약합니다. 개념 기억망은 별도 인공 연상망이며 MaleCNS 회로의 학습 상태가 아닙니다.
- 화면의 발광, 발화량, 연결 개수, 자연스러운 대화만으로 사고나 발전을 입증할 수 없습니다.

## 핵심 실행 경로

환경·감각 → 입력 인코딩 → 신경 활동과 유지되는 내부 상태 → 신경 출력에 따른 행동 선택 → 환경의 결과 → 예측 오차·보상 → 시냅스 변화 → 다음 행동.

신경 회로에서 행동이 선택되는 경로에 LLM의 답변을 정답처럼 주입하지 않습니다. 첫 검증에서는 LLM을 꺼도 감각 반응, 행동 선택, 학습, 저장과 재실행이 동작해야 합니다. 자연어 의문 생성·인터넷 검색까지 신경 회로가 주도하려면 별도의 개념 표현, 기억, 행동 공간과 과제 학습을 검증해야 합니다.

| 필요한 구성 | 구현·검증 기준 |
| --- | --- |
| 실험 신경 회로 | 보존 원본에서 재현 가능한 실험 상태를 만들고 바뀐 시냅스를 실제 신호 계산에 사용 |
| 가소성 | 사전·사후 뉴런 활동, 적격 흔적, 보상 또는 예측 오차가 어떤 연결을 바꿨는지 기록 |
| 안정성 | 가중치 한도·항상성·비정상 발화 제어, 되돌릴 체크포인트 |
| 감각·행동 연결 | 입력 뉴런과 출력 뉴런의 역할·단위·가정 공개, 실제 해부학적 근거와 인위적 할당 구분 |
| 내부 동기 | 낯선 상태·예측 실패를 수치로 정의하고 탐색 행동의 결과와 연결 |
| 경험 기억 | 학습한 회로 상태를 저장하고 재실행 후 같은 조건에서 재현 |
| 모니터 | 입력, 발화, 선택 행동, 결과, 시냅스 변화와 근거를 관찰 가능한 사건으로 표시 |

첫 과제는 작은 감각·행동 환경에서 검증합니다. 먹이 도달률 같은 사전 정의된 성과를 여러 초기 조건에서 측정하고, 학습 전 회로·학습을 끈 회로·학습 후 회로를 같은 미학습 조건에 비교합니다. 가중치만 바뀌고 성과가 개선되지 않았다면 발전으로 보고하지 않습니다.

이는 개발·연구 방향입니다. 공개 연결지도만으로 인간 수준의 사고, 자발적인 자연어 질문, 의식이 생긴다는 보장은 없습니다. 작은 행동 과제의 성공을 일반적인 사고 능력의 완성으로 확대하지 않습니다.

참고: [Shiu et al., Nature 2024](https://www.nature.com/articles/s41586-024-07763-9)의 연결지도 기반 감각·운동 계산 모델과 [Legenstein et al., PLoS Computational Biology 2008](https://doi.org/10.1371/journal.pcbi.1000180)의 보상 조절 가소성 연구는 출발점이며, 이 프로젝트가 해당 학습 결과를 재현했다는 뜻은 아닙니다.
