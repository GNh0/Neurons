# 열린 세계와 생애 규칙

v0.4는 사물·생존·교류·세대 변화와 내부 신경 가소성을 함께 관찰하는 실험 기반입니다. 지구의 모든 사물이나 인간 문명을 구현한 버전은 아닙니다.

## 세계

좌표는 각 축 −1,000,000~1,000,000칸입니다. 초원·숲·돌지대·습지를 시드와 좌표로 생성합니다. 16×16칸 청크의 메모리 캐시는 최대 64개이며 관측 API는 반경 6~24칸만 전송합니다. 화면 가장자리는 세계의 경계가 아닙니다. 소모된 사물의 복구 시각, 제작한 쉼터, 개체의 경험을 저장하므로 탐험 범위 전체를 3D 자산으로 저장하지 않습니다. 방문 감각은 최근 서로 다른 16,384칸까지 유지합니다. 장기 사건·사망 기록과 건축물은 계속 쌓이므로 장기 실행 저장 용량은 증가합니다.

열매·사과·버섯·독버섯·물웅덩이·나무·나뭇가지·돌·섬유 풀·바위 그늘·돌망치·바구니·쉼터가 있습니다. `neurons/catalog.py`의 속성과 제작법을 확장할 수 있습니다. 영양·수분·독성·재료·도구·그늘 효과는 시뮬레이터의 규칙입니다. 독버섯도 영양 입력을 주지만 건강을 잃게 합니다. 돌망치와 바구니는 수집량을 늘리고 쉼터는 다른 개체도 사용할 수 있습니다. 제작법 3개는 제공된 규칙이며 새로운 기술을 스스로 발명했다는 증거가 아닙니다.

## 몸체와 행동

신경 행동 회로의 12개 출력은 북·동·남·서 이동, 조사, 수집, 사용·섭취, 제작, 휴식, 발견 전달, 자원 나눔, 짝짓기입니다. 상호작용 대상은 현재 칸·이동 방향·인접 칸 순서에서 해당 행동에 맞는 사물을 찾습니다. 수분이 65 미만이면 사용 행동은 인접 물을 우선합니다. 이런 신체 처리 규칙을 자율적인 도구 선택의 발견과 혼동하지 않습니다.

조사는 사물의 속성을 개체 기록에 남깁니다. 이미 아는 음식·독성·수분 속성과 재고는 다음 감각 입력에 쓰입니다. 가까운 개체가 전달 행동을 성공하면 해당 사물 기록의 사본과 전달자를 저장합니다. 자원 나눔은 보낸 개체의 재고에서 차감해 받은 개체의 재고로 옮깁니다. 개인 기억이나 행동 가중치를 전 개체에 자동 공유하지 않습니다.

욕구는 배고픔·갈증·피로·안전·호기심·교류·번식의 수치입니다. 신경계로 인코딩되며, 결과에 대한 보상도 학습에 쓰입니다. 주관적으로 느끼는 감정·의식이 있다는 뜻은 아닙니다. 자연어 목적 설명은 LLM의 조사 방향에 쓰이며, 직접 행동의 보상 함수는 앱에서 선택하는 네 가지 기준과 공통 생존·상호작용 결과입니다.

## 생애

- 나이와 생리는 현실 시간이 아닌 **세계 턴**으로 계산합니다. 일시정지하면 세계 전체가 멈추며, 개체 활동을 끄면 해당 개체의 나이와 신경 계산도 멈춥니다.
- 처음 만든 개체는 420턴 나이의 성체입니다. 번식한 자손은 알 60턴 → 유충 240턴 → 번데기 120턴 → 성체 순서로 발달합니다. 유충은 이동·조사·수집·섭취·휴식만 할 수 있습니다. 알·번데기는 행동 없이 저장 에너지를 사용합니다.
- 활성 개체는 세계 턴마다 에너지 0.06×대사율, 수분 0.07×대사율을 사용합니다. 알·번데기는 그 8%입니다. 피로도 증가하며 휴식으로 회복합니다. 에너지·수분이 고갈되거나 피로가 극심하면 건강이 감소합니다. 독성 음식도 손상을 줍니다.
- 건강이 0이 되거나 유전 수명에 도달하면 죽습니다. 자동으로 되살리지 않습니다. 마지막 신경 상태, 경험, 사망 원인, 나이와 가계 기록을 보존합니다. 사망 개체는 살아 있는 계산 개체 8개의 한도에서 제외합니다.
- 서로 다른 성별의 가까운 성체가 에너지 ≥60·수분 ≥50·건강 ≥60이고 번식 대기가 끝났을 때, **짝짓기 출력이 선택되어야** 알이 생깁니다. 거리 조건은 맨해튼 거리 2칸 이내입니다. 부모 각각 에너지 20·수분 10을 쓰고 600턴 동안 다시 번식하지 않습니다. 알을 포함해 8개체 한도에 도달하면 짝짓기는 선택 후보에서 제외하고 이유를 표시합니다.

번식 욕구는 몸체 조건을 충족하면 유전 성향×0.65이며 최대 1입니다. 조건 미달로 욕구 입력이 0일 때도 유전 성향과 미충족 조건을 따로 표시합니다. 욕구 65%가 짝짓기 선택 확률 65%를 의미하지는 않습니다. 반경 32칸 안에서 가장 가까운 번식 가능한 짝의 네 방향 신호를 감각 뉴런으로 보내며, 접근 거리 변화에 0.35×현재 욕구를 곱한 보상을 줍니다. 멀어지면 반대 보상이 적용됩니다. 이는 명시적인 실험 감각·보상 설계이며 실제 초파리 페로몬 시스템을 재현한 것은 아닙니다. 자동 이동·강제 짝짓기는 하지 않습니다.

수명·대사·호기심·교류·번식 성향·학습률은 부모 특성의 평균과 작은 정규분포 변이를 사용합니다. 변이 표준편차는 각 특성 허용 범위의 2.5%이며 범위를 벗어나지 않도록 제한합니다. 수명은 6,000~18,000턴, 최초 기준은 12,000턴입니다. 이 값은 실제 초파리의 수명이나 발달 시간을 보정한 값이 아닙니다.

자손의 원본 연결표는 같은 MaleCNS이며 별도 신경 상태를 새로 만듭니다. 부모의 학습 가중치·개인 지식·LLM 기억은 자동 유전되지 않습니다. 유전 변이와 생존·번식 차이를 관찰할 수 있으나, 장기 적응이나 지능 향상은 통제 비교가 필요합니다.

## 관찰과 검증

세계 패널은 나이·수명·단계·욕구·부모·세대·소지품·사물 지식·발화 확률·학습 가중치·행동 결과를 표시합니다. 집단 지표는 출생·사망·조사한 종류·제작·전달·공유 쉼터의 실제 누계입니다. 문명 점수나 지능 점수를 임의로 만들지 않습니다.

`tests/test_open_world.py`는 실제 자원 소모, 지식 전달, 발달·사망·번식 조건, 사망 기록 재시작, 저장 트랜잭션, 이전 22×4 학습 행렬 이전을 검사합니다. `scripts/validate_open_world.py`는 전체 연결망을 사용한 오프라인 120턴과 신경 가중치 재시작 복원을 검사합니다. 임시 UI 시험의 출생·사망 사례는 화면 검사 조건으로 구성한 사례이며, 자율 번식 성능의 증거로 집계하지 않습니다.
