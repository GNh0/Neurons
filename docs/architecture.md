# 구현 구조

공식 Feather 3개 → prepare_connectome.py → CSR 연결망·메타데이터 → Simulation → 로컬 HTTP API → WebGL 지도.

superclass가 비어 있지 않은 모든 뉴런을 선택합니다. 양 끝이 선택 집합에 있는 원본 양수 연결을 모두 유지합니다. 원본 신뢰도 0.5 기준 외에 추가적인 강도 절단은 하지 않습니다. 고립된 뉴런도 개별 상태를 갖습니다.

## 계산과 표시

CSR 행은 presynaptic, 열은 postsynaptic이며 가중치는 접촉 개수입니다. 역방향 탐색에 CSC를 사용합니다. 뉴런별 막전위, 불응기, 발화 횟수, 최근 활동을 갖습니다. 1 ms마다 누설·지연 입력·자극·발화·재설정을 계산합니다.

지연 2 ms, 불응기 3 ms, 휴지·재설정 -52 mV, 임계 -45 mV, 시간상수 20 ms, 접촉당 0.275 mV입니다. GABA·글루탐산·히스타민은 억제로 가정하고 조절성·미상은 빠른 전류 효과 0입니다.

발화한 뉴런의 전체 출력 행을 계산합니다. 화면 표시용 선 표본은 계산에 영향을 주지 않습니다. 원본 좌표는 8 nm voxel을 0.008배 해 µm로 저장합니다. 수상돌기 표면과 개별 시냅스 좌표는 가져오지 않습니다. 계산은 CPU, 표시는 WebGL GPU이며 약 350 ms마다 화면 상태를 조회합니다.

## 기억·언어·모듈

Modules는 SQLite 기억, 검색, 피드백, 로컬 LLM과 모듈 설정을 관리합니다. 기억은 단어·개념 겹침과 강도로 순위를 매깁니다. 뇌 연결망이나 LLM의 가중치를 훈련하지 않습니다.

register(Module(...), handler)로 로컬 처리기를 등록하고 execute(id, **payload)로 활성 상태를 확인한 뒤 호출합니다. 새 입력·연구 기능을 이 인터페이스로 연결할 수 있습니다. 임의 Python 파일을 자동 로드하거나 외부 코드를 실행하지 않습니다.

LLM에는 실제 관측 상태와 참조 기억, 최근 대화가 전달됩니다. 출력은 기억으로 자동 저장하지 않습니다. 처리 기록은 실제 실행 단계이며 숨은 사고 과정이 아닙니다.

## 실행 경계와 확장

서버는 loopback에만 바인딩하며 Host와 POST Origin을 검사합니다. 정적 파일은 명시된 파일만 제공합니다. 인터넷 자료 수집은 이 보존 버전에 없습니다. 뉴런 상태는 프로세스 재시작 시 초기화되고 기억·모듈 설정·대화만 지속됩니다.

향후 몸·세계 모듈은 감각 인코더 → 신경계 → 운동 디코더 → 물리 환경 → 평가의 명시적 인터페이스로 연결합니다. 모델·질감은 재사용하고 물체 인스턴스 상태를 따로 저장합니다. 작은 먹이 탐색 환경의 행동 지표를 먼저 검증한 뒤 확장합니다. 이 문단은 향후 설계이며 구현 완료 기능이 아닙니다.
