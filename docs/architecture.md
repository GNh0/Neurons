# 실행 구조

MaleCNS 원본 → CSR 연결망 → LIF 계산 → 관측 API → WebGL 원본 지도.

탐구 목표 → 로컬 LLM 질문 → 공개 검색 → 자료 읽기 → 로컬 요약·근거 평가 → 경험 기억 → 개념 노드·연결 갱신 → 후속 의문.

## 원본 신경계

superclass가 비어 있지 않은 166,700개 뉴런을 선택합니다. 양 끝이 선택 집합에 있는 양수 연결을 모두 유지하고 추가적인 강도 절단을 하지 않습니다. CSR 행은 presynaptic, 열은 postsynaptic이며 가중치는 접촉 개수입니다. 역방향 조회에는 CSC를 사용합니다.

1 ms마다 누설·지연 입력·직접 자극·발화·재설정을 계산합니다. 지연 2 ms, 불응기 3 ms, 휴지·재설정 -52 mV, 임계 -45 mV, 시간상수 20 ms, 접촉당 0.275 mV입니다. GABA·글루탐산·히스타민은 억제, 조절성·미상은 빠른 전류 효과 0으로 가정합니다.

발화한 뉴런의 전체 출력 행이 계산에 사용됩니다. 개별 접촉의 생화학·수상돌기 상태는 계산하지 않습니다. 8 nm voxel 좌표를 0.008배 하여 µm로 저장합니다. 계산은 CPU, 표시는 WebGL이며 상태 조회는 약 350 ms 간격입니다.

## 가소성 학습망

LearningNetwork는 별도 인공 개념 뉴런을 SQLite에 저장합니다. 기억당 최대 18개 개념을 연결하고 동시 등장 시 0.1씩 강화하여 3에서 제한합니다. 새 연결은 0.2에서 시작합니다. 피드백은 관련 연결에 +0.08 또는 -0.12를 적용하고 0.02–3으로 제한합니다.

기억 검색에서 질문 개념을 활성화하고, 가중치와 연결 차수로 정규화한 신호를 네 번 전파합니다. 감쇠 계수는 0.65입니다. 이 활성도와 직접 단어 겹침·기억 강도가 검색 순위를 결정합니다. 이 규칙은 생물학적 STDP나 원본 초파리 시냅스 훈련이 아닙니다.

## 자율 탐구

Research의 별도 작업 스레드가 제한된 회차를 수행합니다. 질문·검색어·출처·읽은 범위·요약·불확실성·학습 결과·후속 의문과 실패를 기록합니다. LLM 출력에는 [Ollama JSON 구조화 출력](https://docs.ollama.com/capabilities/structured-outputs)을 사용하고 실제 읽은 출처 ID를 확인합니다.

DuckDuckGo 검색과 Europe PMC의 논문 초록을 조회합니다. 결과가 없으면 한 번만 검색어를 넓힙니다. 자료는 공개 HTTP 주소만 읽고 리다이렉트 주소도 검사하며 요청별 시간·용량을 제한합니다. 로그인·CAPTCHA·접근 거절을 우회하지 않습니다. 검색 요약만 얻은 경우는 본문을 읽었다고 기록하지 않습니다. 알려진 위키·AI 요약 집계 사이트는 학습 근거에서 제외합니다.

출처 요약은 독립 검증된 사실이 아닙니다. 근거가 부족하거나 참조가 잘못된 경우 저장하지 않습니다. 부분적으로만 답한 경우 미해결 내용을 남깁니다. 자체 코드를 고치거나 다운로드한 프로그램을 실행하는 기능은 없습니다.

## 모듈과 저장

IndividualLab은 알을 포함해 최대 8개체의 개별 Simulation 상태를 만들고, 원본 CSR/CSC와 주석을 공유합니다. 신경 상태·난수·지연 큐·행동 가중치·경험·텍스트 기억은 개체별입니다. 세계 한 턴에 활성 개체 모두의 나이·대사를 갱신하고, 행동 가능한 유충·성체 중 하나의 신경계를 순서대로 계산합니다. 알·번데기만 있어도 발달 시간은 흐릅니다. 사망 개체는 신경 체크포인트와 생애 기록을 보존한 뒤 메모리에서 해제합니다. LLM 호출 잠금만 공유하며 개인 기억은 전달 행동 없이 합치지 않습니다.

환경 입력 → NeuralAdapter → 전체 LIF 계산 → SpikingPolicy → OpenWorld.act → 보상 가중치 갱신 → IndividualStore 사건 기록의 순서입니다. `catalog.py`가 사물·재료·제작법·행동 목록을, `life.py`가 발달·욕구·유전·사망 규칙을 제공합니다. OpenWorld는 16×16 청크를 좌표로 생성하고 LRU 캐시 64개만 유지합니다. 고정 지형 전체를 파일로 만들지 않으며 소모 시각·건축물·경험이 저장됩니다. 개체별 LLM 보조는 별도 Research 인스턴스를 사용하고 목표·설정이 바뀌면 오래된 제안을 무효화합니다. 대기하던 LLM 요청도 활성 상태를 다시 검사합니다.

IndividualStore는 PostgreSQL의 neurons 스키마 또는 SQLite에 세계/개체 상태와 사건을 저장합니다. 신경 배열을 먼저 고유 이름의 NPZ로 기록하고 체크포인트 참조·세계·실행 순서·대기 사건을 하나의 DB 트랜잭션으로 갱신합니다. DB 성공 뒤 살아 있는 개체의 최신 두 신경 파일을 유지합니다. 죽은 개체는 마지막 파일과 공개 요약을 남기며, 최근 30개 사망 개체가 선택 목록에 표시됩니다. 모든 사망 기록은 DB에 보존됩니다. 이전 22×4 행동 회로는 이름/기존 순서에 따라 50×12 회로에 옮기고 신규 연결은 0으로 시작합니다. 큰 원본 그래프는 메모리에서 계산하며 SQL 조회를 매 시냅스 계산에 사용하지 않습니다.

Modules.register(Module(...), handler), execute(id, **payload)로 처리기를 등록하고 활성 상태를 검사합니다. 언어모델 요청은 잠금으로 직렬화합니다. 언어·웹·기억 모듈을 해제하면 자율 연구의 다음 단계가 중단됩니다. 모든 LLM 호출은 loopback Ollama로 전달됩니다.

공용 기능과 각 개체는 각자의 SQLite DB에 텍스트 기억·연상 그래프·대화·연구 이력을 저장합니다. 재시작하면 미완료 연구는 interrupted로 기록되고 자동 재개하지 않습니다. 개체의 LIF 상태는 체크포인트로 복원하며, 공용 관측실의 시험 LIF 상태는 저장하지 않습니다.

HTTP 서버는 loopback 바인딩, Host·POST Origin 검사, 명시적 정적 파일 목록을 사용합니다. HTML 파일을 직접 열면 실행 안내를 보여주고 HTTP 경로에서는 앱 모듈을 시작합니다.
