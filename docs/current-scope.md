# 현재 범위

구현: 실제 MaleCNS 전체 분류 뉴런의 단순화 LIF 계산, 3D 관측실, 로컬 LLM 대화, 공개 자료 자율 탐구, 별도 가소성 연상 학습망, 기록과 저장, Windows 배포.

보존: baseline 브랜치와 초기 배포에는 원본 데이터와 관측실의 기준 버전을 남깁니다. main에는 관측실·자료 수집 보조·인공 연상 기억망을 함께 둡니다.

v0.3: 개체별 독립 신경 상태, 절차 생성 오픈월드, 13종 사물과 12개 행동, 도구 제작과 지식·자원 전달, 욕구·성장·수명·죽음·번식·유전 변이, 체크포인트 복원, LLM의 출처 기반 경험 복습 보조, 선택 개체 3D 뉴런 지도, PostgreSQL 상태·사건 저장을 추가합니다. 신경 활동이 실제 행동과 학습 갱신에 쓰입니다. 원본 25,582,938개 연결은 고정이고 추가한 600개 행동 시냅스만 학습합니다. [neural-core.md](neural-core.md)와 [living-world.md](living-world.md)에 계산 경로와 한계를 명시합니다.

향후: 해부학적 감각·운동 매핑, 초파리 물리 몸체, 더 넓은 사물·상호작용 목록, 새로운 제작 원리의 발견, 원본 회로의 검증 가능한 가소성. 자연어 질문은 여전히 LLM이 만듭니다. 생애·유전·번식 규칙의 실행을 장기적인 적응 진화나 인간 문명의 출현으로 보고하지 않습니다. 원본 뇌 전체의 생물학적 학습·자동 코드 진화·일반 지능 향상은 구현 완료 항목이 아닙니다.
