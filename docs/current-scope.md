# 현재 범위

구현: 실제 MaleCNS 전체 분류 뉴런의 단순화 LIF 계산, 3D 관측실, 로컬 LLM 대화, 공개 자료 자율 탐구, 별도 가소성 연상 학습망, 기록과 저장, Windows 배포.

보존: baseline 브랜치와 초기 배포에는 원본 데이터와 관측실의 기준 버전을 남깁니다. main에는 관측실·자료 수집 보조·인공 연상 기억망을 함께 둡니다.

핵심 목표: 뉴런·시냅스 회로가 판단과 행동 학습의 주체가 되어야 합니다. 현재는 회로 가중치가 고정되어 있어 이 목표를 달성하지 못했습니다. LLM 자료 수집을 이 목표의 완성으로 간주하지 않습니다. 필요한 실행 경로와 검증 기준은 [neural-core.md](neural-core.md)에 있습니다.

향후: 초파리 몸·감각·운동과 물리 세계 연결, 과제로 측정하는 행동 학습. 몸·세계, 원본 뇌의 생물학적 가소성, 자동 코드 진화, 일반 지능 향상은 구현·검증 완료 항목이 아닙니다.
