# 현재 범위

구현: 실제 MaleCNS 전체 분류 뉴런의 단순화 LIF 계산, 3D 관측실, 로컬 LLM 대화, 공개 자료 자율 탐구, 별도 가소성 연상 학습망, 기록과 저장, Windows 배포.

보존: baseline 브랜치와 초기 배포에는 원본 데이터와 관측실의 기준 버전을 남깁니다. main에는 관측실·자료 수집 보조·인공 연상 기억망을 함께 둡니다.

v0.4: 오픈월드·생애·교류 기반에 개체별 내부 연결 가소성을 추가했습니다. 25,582,938개 집계 연결의 효율 배열이 개체마다 독립적이며, 발화한 뉴런의 연결은 보상·활동 조절로 변하고 실제 LIF 전류 전달에 사용됩니다. 54입력×12행동의 648개 행동 가중치도 학습합니다. 번식 조건과 유전 성향을 표시하고 주변 짝의 방향 감각과 접근 보상을 제공합니다. [neural-core.md](neural-core.md)와 [living-world.md](living-world.md)에 계산 경로와 한계를 명시합니다.

향후: 해부학적 감각·운동 매핑, 초파리 물리 몸체, 더 넓은 사물·상호작용 목록, 새로운 제작 원리의 발견, 새 연결 생성·제거, 학습의 장기 성능 비교. 자연어 질문은 여전히 LLM이 만듭니다. 생애·유전·번식 규칙의 실행을 장기적인 적응 진화나 인간 문명의 출현으로 보고하지 않습니다. 원본 뇌 전체의 생물학적 학습·자동 코드 진화·일반 지능 향상은 구현 완료 항목이 아닙니다.
