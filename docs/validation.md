# 검증 기록

2026-09-13, Windows, RAM 32 GiB, RTX 3080 10 GB, Python 3.10.

- v0.2.0: 독립 5뉴런 회로와 임시 SQLite에서 27개 테스트 통과. 무입력 안정 상태, 2 ms 전달 지연, 접촉 수 가중치, 억제 반응, 3 ms 불응기, 10 ms 진행을 확인했습니다.
- 한글 검색, 중복 학습, DB 재개방 후 저장 유지, 피드백에 따른 순위 변화, 모듈 차단과 재시작 후 설정을 확인했습니다.
- API 바이너리 길이, 학습·내보내기, 잘못된 입력과 외부 Origin·Host 거절을 확인했습니다.
- 전체 CSR의 166,700개 뉴런, 25,582,938개 양수 연결, 접촉 가중치 합 124,177,617개와 인덱스·정규형·메타데이터 순서를 확인했습니다.
- 두 DNp01 뉴런에 100 ms 시험 자극: 계산에 1.419초, 총 327,743회 발화, 37,516개 뉴런이 발화했습니다. 계산/현실 시간 비율 약 0.0705입니다. 다른 앱 실행 여부에 따라 달라질 수 있습니다.
- 실제 브라우저에서 전체 3D 지도, 뉴런 선택과 자극 후 활동, 로컬 Qwen3.5:4b의 한국어 응답을 확인했습니다. 정지 상태의 화면은 관측 당시 약 153–170 FPS였습니다.
- 공식 원본 3개 파일의 GCS MD5 및 독립 보존 복사본의 SHA256 일치를 확인했습니다. original-data-verification.json에 해시가 있습니다.

추가 검증: 개념 활성의 간접 기억 검색, 피드백 후 연결 강도 저장, 확장 중단, 공개 주소 검사, 탐구 중단, 잘못된 출처 참조·근거 부족 시 학습 보류, 관련 자료 우선순위와 알려진 집계 출처 제외를 확인했습니다. JavaScript 구문 검사와 브라우저의 원본·학습 지도 전환을 확인했습니다.

실제 Qwen3.5:4b와 인터넷을 사용하는 별도 임시 DB에서 두 회차를 수행했습니다. 첫 회차의 출처 요약은 기억 1개·개념 노드 18개·연결 153개를 만들었고, 후속 질문은 근거 부족으로 저장을 보류했습니다. 이는 실행 경로 검증이며 생성된 과학 설명을 독립적으로 검증한 결과는 아닙니다.

v0.2.0 Windows 실행 파일에서 Python 별도 설치 없이 166,700개 뉴런 로드와 로컬 모델 연결을 확인했습니다. 분리된 배포 테스트 DB에서 실제 검색·읽기·요약 한 회가 완료되었으며 출처 4개, 기억 1개·노드 18개·연결 153개가 기록됐습니다. 실제 다른 PC에서 실행한 검증은 아닙니다.

HTTP 실행에서 CSS·JavaScript·WebGL을 확인했습니다. file:// 직접 열기의 안내 분기는 코드에 포함되지만, 자동화 브라우저의 URL 정책이 로컬 파일 열기를 차단하여 그 분기의 실제 브라우저 시각 검증은 수행하지 못했습니다. 권장 실행 방법은 Run Neurons.cmd입니다.

구현의 계산·저장·자료 수집 동작 검증입니다. 실제 초파리 행동, 신경 회로 자체의 자율학습·사고, 의식이나 생물학적 정확도를 검증한 결과가 아닙니다. 원본 회로의 가중치는 여전히 고정이며 필요한 핵심 변경은 neural-core.md에 명시했습니다.
