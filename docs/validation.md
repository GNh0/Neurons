2026-09-13, Windows, RAM 32 GiB, RTX 3080 10 GB, Python 3.10.

- v0.2.0: 독립 5뉴런 회로와 임시 SQLite에서 27개 테스트 통과. 무입력 안정 상태, 2 ms 전달 지연, 접촉 수 가중치, 억제 반응, 3 ms 불응기, 10 ms 진행을 확인했습니다.
- 한글 검색, 중복 학습, DB 재개방 후 저장 유지, 피드백에 따른 순위 변화, 모듈 차단과 재시작 후 설정을 확인했습니다.
- API 바이너리 길이, 학습·내보내기, 잘못된 입력과 외부 Origin·Host 거절을 확인했습니다.
- 전체 CSR의 166,700개 뉴런, 25,582,938개 양수 연결, 접촉 가중치 합 124,177,617개와 인덱스·정규형·메타데이터 순서를 확인했습니다.
- 두 DNp01 뉴런에 100 ms 시험 자극: 계산에 1.419초, 총 327,743회 발화, 37,516개 뉴런이 발화했습니다. 계산/현실 시간 비율 약 0.0705입니다. 다른 앱 실행 여부에 따라 달라질 수 있습니다.
- 실제 브라우저에서 전체 3D 지도, 뉴런 선택과 자극 후 활동, 로컬 Qwen3.5:4b의 한국어 응답을 확인했습니다. 정지 상태의 화면은 관측 당시 약 153–170 FPS였습니다.
- 공식 원본 3개 파일의 GCS MD5 및 독립 보존 복사본의 SHA256 일치를 확인했습니다. original-data-verification.json에 해시가 있습니다.

추가 검증: 개념 활성의 간접 기억 검색, 피드백 후 연결 강도 저장, 확장 중단, 공개 주소 검사, 탐구 중단, 잘못된 출처 참조·근거 부족 시 학습 보류, 관련 자료 우선순위와 알려진 집계 출처 제외를 확인했습니다. JavaScript 구문 검사와 브라우저의 원본·학습 지도 전환을 확인했습니다.

실제 Qwen3.5:4b와 인터넷을 사용하는 별도 임시 DB에서 두 회차를 수행했습니다. 첫 회차의 출처 요약은 기억 1개·개념 노드 18개·연결 153개를 만들었고, 후속 질문은 근거 부족으로 저장을 보류했습니다. 이는 실행 경로 검증이며 생성된 과학 설명을 독립적으로 검증한 결과는 아닙니다.

v0.2.0 Windows 실행 파일에서 Python 별도 설치 없이 166,700개 뉴런 로드와 로컬 모델 연결을 확인했습니다. 분리된 배포 테스트 DB에서 실제 검색·읽기·요약 한 회가 완료되었으며 출처 4개, 기억 1개·노드 18개·연결 153개가 기록됐습니다. 실제 다른 PC에서 실행한 검증은 아닙니다.

HTTP 실행에서 CSS·JavaScript·WebGL을 확인했습니다. file:// 직접 열기의 안내 분기는 코드에 포함되지만, 자동화 브라우저의 URL 정책이 로컬 파일 열기를 차단하여 그 분기의 실제 브라우저 시각 검증은 수행하지 못했습니다. 권장 실행 방법은 Run Neurons.cmd입니다.

위 v0.2 검증은 계산·저장·자료 수집 경로의 검사이며 당시 원본 회로는 고정이었습니다. 실제 초파리 행동·사고·의식이나 생물학적 정확도를 검증한 결과가 아닙니다. v0.4의 내부 가소성 검사는 아래에 별도로 기록합니다.

## v0.3 오픈월드·생애 통합

전체 테스트 54개: 기존 신경·저장·LLM 차단 검사와 사물 조사·실제 자원 소모·도구 제작·지식 전달·번식 조건·발달·사망 보존·저장 트랜잭션·이전 회로 이전을 확인합니다. 사물 조사 후 기억에 따라 다음 감각 입력이 바뀌는 것도 검사합니다.

전체 MaleCNS 연결망으로 로컬 LLM을 끄고 120세계 턴을 실행한 통합 시험은 36.62초 걸렸습니다. 2개체가 120개 행동 경험을 쌓았고 사물 2종 조사, 제작 1회를 기록했습니다. 출생·사망·교류 성공은 이 짧은 실행에서 0회였습니다. 네트워크 호출 없이 동작했고 원본 연결 가중치 해시가 유지됐으며, 재시작 후 개체의 나이·행동 수·600개 행동 가중치가 동일했습니다. 이는 경로 검증이며 학습 전후 지능 향상의 증거가 아닙니다.

기존 PostgreSQL 세계는 적용 전에 별도로 백업했습니다. 두 개체의 이전 22×4 행동 가중치와 막전위·불응기·발화 수·활동·지연 배열이 새 50×12 회로의 대응 위치와 정확히 일치하는 것을 확인했습니다. 큰 신경 배열은 로컬 NPZ에, 세계·사물 기억·생애·행동·파일 참조는 PostgreSQL에 저장됩니다.

격리된 전체 연결망 UI 시험에서 지도 반경 변경, 좌표 이동 후 주변 청크 로드, 한 턴 실행, 알·사망 개체 선택, 사망 개체의 조작 차단, 작은 화면에서도 실행 버튼 표시를 확인했습니다. 브라우저 오류 로그는 없었습니다. UI 출생·사망 사례는 시험 조건으로 구성했으며 자율 행동 성능 자료에 포함하지 않았습니다.

앞선 네 방향·88가중치의 작은 Arena 통제 실험에서는 목표별 600회 학습 후 별도의 3개 시드에서 학습 전후 각 120회 평가했습니다. 먹이 목표의 먹이 합은 9→17, 충돌 61→32였고, 탐색 목표의 방문 수 합은 104→132, 충돌 61→27이었습니다. 정규화 전 회로에서 탐색이 나빠진 초기 실패도 남겼습니다. 이 결과는 현재 12행동 오픈월드의 성능 측정으로 전용하지 않습니다.

별도 이전 4행동 회로의 실제 로컬 LLM 자료 탐구에서는 출처 기억 1개와 실제 경험 16개 복습을 확인했습니다. LLM 요약의 과학적 정확성, 12행동 세계의 장기 학습 효과, 세대 간 적응·지능 향상이나 문명의 출현은 검증하지 않았습니다.

최종 Windows 실행 파일의 별도 시험 복사본에서도 실제 PostgreSQL 연결로 기존 두 개체·전체 뉴런·600개 행동 시냅스·오픈월드 로드와 로컬 LLM 연결 감지를 확인했습니다. 세계 행동을 보내지 않고 종료한 뒤 기존 PostgreSQL 상태와 사건 수의 불변을 확인했습니다. ZIP의 1,248개 파일 CRC 검사 및 사용자 DB·연결 자격 증명·LLM 모델 제외 검사를 통과했습니다. Python이나 PostgreSQL이 없는 별도 PC에서의 실행은 검증하지 않았습니다.

## v0.4 내부 연결 가소성과 번식 관찰

총 65개 단위·통합 테스트가 통과했습니다. 검사에는 보상 부호에 따른 내부 연결 변화, 그 변화로 실제 도착 뉴런의 발화가 달라지는 인과 검사, 원본·개체 간 분리, 학습 중단, 효율 범위, 저장 재사용·복원, 자손 학습 상태 초기화, v0.3의 600개 가중치 이전, 번식 조건별 설명·후보 제외·범위 제한 감각·접근 보상이 포함됩니다.

`scripts/validate_internal_plasticity.py`는 사용자 DB와 분리한 전체 MaleCNS 세계에서 네트워크 호출 없이 120턴과 복원 후 비교 1턴을 실행했습니다. 실행 중앙값은 행동당 0.527초, 95백분위는 0.619초였고 전체 검사에 70.42초가 걸렸습니다. 내부 효율·활동 평균·행동 가중치가 정확히 복원되고 다음 행동·막전위·효율이 일치했습니다. 원본 접촉 배열의 SHA256은 유지됐습니다. 내부 가중치 배열은 개체당 102,331,752바이트입니다.

이 시험에서 2개체·121행동·사물 2종 조사, 출생 0회가 관측됐습니다. 내부 가소성 및 번식 감각 보완이 장기 생존이나 번식률을 개선했는지는 아직 통제 비교로 검증하지 않았습니다. 가중치 변화나 강제로 구성한 출생 사례를 지능·진화 향상 증거로 사용하지 않습니다.
