# 향후 초파리 몸과 세계 연결

아직 구현되지 않은 확장 설계입니다. 먼저 먹이·물·벽·장애물이 있는 작은 공간에서 생존·탐색 행동을 검증하고 물체 종류를 늘립니다.

| 모듈 | 입력과 출력 |
| --- | --- |
| World | 물체 위치, 충돌, 광원, 냄새장, 먹이와 물의 양, 시간 |
| Body | 몸·날개·다리 상태와 관절, 운동 명령을 물리적인 움직임으로 변환 |
| Sensors | 몸의 위치에서 시각·후각·접촉 관측 생성 |
| NeuralAdapter | 관측을 신경 입력으로, 운동 뉴런 출력을 몸의 제어량으로 변환 |
| Learning | 과제 결과와 경험을 사용해 지정된 학습 규칙을 업데이트 |
| Evaluation | 먹이 도달률, 충돌 수, 소비 에너지, 생존 시간과 미학습 환경의 성과 |

감각·운동 뉴런 유형, 좌우·몸 축, 시간 단위와 운동 디코딩을 확인해야 합니다. 원본의 전달물질·수용체·근육 연결 정보만으로 부족한 파라미터는 모델 가정으로 표시합니다. LLM은 실험 계획·기록 설명을 맡고, 지속적인 운동 제어는 정해진 시간 간격의 환경·신경계 루프로 설계합니다.

## 용량과 성능

물체의 모양과 질감은 한 번 저장하고 배치별 위치·상태만 저장합니다. 예를 들어 모델 500종 × 2 MB = 1 GB이고, 같은 모델을 1,000번 배치한다고 모양 파일을 1,000번 복사하지 않습니다. 이 수치는 설계 예시이며 실제 게임 자산 용량을 측정한 값이 아닙니다.

뉴런 166,700개의 막전위 하나씩을 float32로 매 1 ms마다 기록하면 166,700 × 4 × 1,000 = 666.8 MB/초가 됩니다. 따라서 모든 상태의 무제한 저장 대신 사건 기록, 선택 뉴런 시계열, 주기적인 체크포인트와 보관 한도를 사용해야 합니다. 현재 모니터는 전체 막전위 이력을 디스크에 계속 기록하지 않습니다.

저장 공간 외에 GPU 메모리와 계산 시간을 별도로 관리합니다. 현재 LIF CPU 계산은 이 PC의 예시 자극에서 생물학적 100 ms에 약 1.4초가 걸렸습니다. 물리와 렌더링, LLM을 동시에 실행하려면 느린 시뮬레이션 시간, 감각 처리 주기, 별도 계산 프로세스 또는 커널 최적화를 검토해야 합니다.

노드·연결 개수 증가만으로 발전을 판정하지 않습니다. 같은 조건의 과제 성과와 새로운 환경의 성과를 비교하고, 개선이 없거나 퇴행한 학습 변경을 되돌릴 수 있게 설계합니다.
