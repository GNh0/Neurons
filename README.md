# Neurons · CNS Observatory

실제 MaleCNS 연결망의 3D 관측실, 개체별 경험 학습 세계, 로컬 LLM 자료 보조를 함께 실행하는 Windows 앱입니다.

v0.3에서는 개체가 열린 지형에서 사물을 조사하고 수집·섭취·제작·교류·번식을 시도합니다. 각 개체는 독립된 166,700개 LIF 상태와 12개 행동 뉴런·600개 학습 시냅스를 갖습니다. 알·유충·번데기·성체로 성장하고, 필요를 충족하지 못하거나 수명이 끝나면 죽습니다. 원본 MaleCNS 연결 가중치는 고정입니다. [실제 학습 범위](docs/neural-core.md)와 [세계·생애 규칙](docs/living-world.md)을 확인하세요.

| 구성 | 실제 역할 |
| --- | --- |
| MaleCNS 신경계 | 166,700개 뉴런, 25,582,938개 가중 연결, 124,177,617개 접촉의 LIF 계산 |
| 개체와 세계 | 감각·욕구·사물 기억 → 신경 활동 → 이동·조사·도구·교류·번식 → 실제 결과 → 행동 시냅스 갱신 |
| 자율 탐구 | 질문 생성 → 인터넷 검색 → 원문·초록 읽기 → 출처 기반 요약 → 저장 또는 보류 → 다음 의문 |
| 학습 연결망 | 경험에서 개념 노드와 연상 연결을 만들고, 연결의 활성 전파로 기억 검색 |
| 로컬 LLM | 탐구 계획, 자료 요약과 자연어 대화 |

행동 회로의 학습 가중치와 인공 연상망이 바뀝니다. 원본 초파리 가중치·LLM 가중치·뉴런 개수는 바꾸지 않습니다. 의식이나 지속적인 일반 지능 향상을 입증한 시스템은 아닙니다.

## 가장 간단한 실행

[최신 Windows 배포본](https://github.com/GNh0/Neurons/releases/latest)을 압축 해제하고 **Run Neurons.cmd**를 실행합니다. Python 실행 환경, 원본·컴파일 뉴런 데이터와 필수 라이브러리가 포함됩니다. 로컬 LLM 모델과 Ollama는 제외합니다.

지도·자극 실험·개체의 행동과 경험 학습은 LLM 없이 실행됩니다. 대화와 자료 탐구는 [Ollama](https://ollama.com/download/windows)를 설치하고 로컬 모델을 준비하세요.

```powershell
ollama pull qwen3.5:4b
```

Ollama 실행 후 앱의 **모듈 → 연결 다시 확인**을 누릅니다. 포트 11434와 11435를 확인하며 설치된 다른 로컬 모델도 선택할 수 있습니다. 기본 관측실 주소는 http://127.0.0.1:8877 입니다.

**web/index.html을 직접 여는 것은 앱 실행이 아닙니다.** 직접 열면 실행 안내가 표시됩니다. 뉴런 계산과 데이터 조회에는 함께 실행되는 로컬 서버가 필요합니다.

## 자율 탐구

**개체와 세계**에서 세계를 실행하면 루미(생존과 발견)와 노바(새 지역 탐색)가 독립적으로 행동합니다. 기존 저장 개체의 목적은 유지합니다. 알을 포함해 최대 8개체를 동시에 계산하며 사망한 개체의 기록은 별도로 남깁니다. 행동 보상은 생존과 발견·먹이 확보·새 지역 탐색·교류와 공동 생활 중 선택합니다. 자연어 목적은 자료 탐구에 사용합니다.

지도를 드래그해 이동하고 휠로 확대하며, **선택 개체 따라가기**로 돌아옵니다. 초원·숲·돌지대·습지는 좌표에서 절차 생성하고 화면 주변만 불러옵니다. 13종 사물과 3개 제작법이 첫 확장 기반에 포함됩니다. 소지품·조사한 사물·욕구·나이·부모·세대·출생·사망·제작·전달 기록을 볼 수 있습니다. 세계 지도는 등각 투영 Canvas 표현이며 물리적 날갯짓을 계산하는 초파리 몸체 모델은 아닙니다.

자손은 부모의 유전 특성 평균과 작은 변이를 이어받고, 개인 기억과 학습 가중치는 새로 시작합니다. 사물 지식은 가까운 개체의 전달 행동으로 배울 수 있습니다. 제작법과 생애 규칙은 제공된 실험 조건이며, 문명이나 인간 수준 지능이 출현했다고 주장하지 않습니다.

LLM 보조를 켠 개체는 10회 행동 이후 목표와 관측에서 질문을 만들고, 최대 3분에 한 번 한 회차씩 자료를 조사합니다. 출처가 저장되면 자신의 실제 경험 중 복습할 종류를 제안하고 최대 16개의 실제 보상으로 같은 행동 가중치를 갱신합니다. LLM이 실시간 행동이나 보상을 대신 지정하지 않습니다. LLM을 꺼도 기존 신경 상태·가중치가 유지되며 경험 학습이 계속됩니다. **이 개체의 3D 뉴런맵**에서 해당 개체의 발화와 막전위를 볼 수 있습니다.

기존의 공용 **자료 탐구** 기능도 계속 사용할 수 있습니다.

1. **자료 탐구**에서 목표와 반복 횟수·간격을 지정합니다. 기본 목표는 뉴런·뇌·AI의 학습 원리입니다.
2. 시작하면 로컬 모델이 질문과 검색어를 만들고 공개 자료를 읽습니다.
3. 출처가 연결된 요약을 저장하거나, 근거가 부족하면 학습을 보류합니다. 원문 읽기 실패와 실행 오류도 기록합니다.
4. 결과에서 생긴 후속 의문을 다음 회차로 이어갑니다.
5. **학습 연결망**을 누르면 생성된 개념 노드와 연결을 3D로 봅니다. **원본 신경계**로 되돌릴 수 있습니다.

검색어는 DuckDuckGo 등 검색 서비스와 Europe PMC에 전송됩니다. LLM 추론은 로컬에서 수행합니다. 웹 자료와 생성 요약은 독립 검증 전입니다. 출처 URL·읽기 범위·불확실성을 확인하고 기억의 강화·약화 기능으로 피드백할 수 있습니다.

한 번에 1–100회, 회차 간격 5–600초를 지정합니다. 중단 버튼은 진행 중인 요청이 정리되는 다음 단계에서 멈춥니다. 필요한 모듈을 끄면 다음 단계로 진행하지 않습니다. 연속 오류 3회에는 종료하며 재시작 후 자동 탐구는 시작되지 않습니다.

## 3D 표시의 의미

원본 지도 점은 세포체 또는 세포체 연결부이며 개별 접촉의 좌표가 아닙니다. 전체 계산 그래프는 표본화하지 않지만, 전체 보기의 선은 16,000개 표시용 표본입니다. 선택 뉴런에는 입력·출력 각각 최대 180개를 표시합니다. 좌표가 없는 26,062개 뉴런도 계산에 포함됩니다.

학습 지도는 개념 노드의 비해부학적 3D 배치입니다. 동시 등장한 개념의 연결을 강화하고 정규화한 활성 전파를 기억 검색에 사용합니다. 화면에는 최대 1,500개 노드와 6,000개 연결을 표시하며 저장·검색은 전체 학습망을 사용합니다. 현재 저장 한도는 기억 10,000개, 학습 노드 10,000개, 학습 연결 200,000개입니다.

## 소스에서 실행

Python 3.10 이상이 설치된 Windows PowerShell:

```powershell
git clone https://github.com/GNh0/Neurons.git
cd Neurons
.\setup.ps1
.\start.ps1 -OpenBrowser
```

설치 스크립트는 전용 가상 환경, 공식 원본 다운로드 약 1.11 GB, MD5 확인, 연결망 컴파일을 수행합니다. 코드 저장소에는 데이터·모델·실행 환경과 사용자 DB가 포함되지 않습니다. 이 PC에서는 RAM 32 GB와 RTX 3080 10 GB로 검증했습니다. 뉴런 계산은 CPU, 3D 표시는 GPU를 사용하며 생물학적 실시간 속도를 보장하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe scripts\validate_full_graph.py
.\.venv\Scripts\python.exe scripts\validate_research_live.py
```

마지막 검증 명령은 실제 인터넷 검색과 로컬 LLM을 사용하고 임시 기억 DB에서 실행합니다.

## 저장과 보존

공용 기억·대화는 `.data/memory.sqlite3`에 보존됩니다. 개체별 텍스트 기억·대화·탐구 기록은 `.data/individuals/<개체 ID>/memory.sqlite3`, 신경 상태와 학습 가중치는 같은 폴더의 압축 체크포인트에 저장합니다. 세계·목표·생애·사물 기억·경험 사건과 체크포인트 참조는 PostgreSQL 또는 독립 SQLite 저장소에 기록합니다. 25세계 턴마다, 사망 처리 시, 상태 저장·일시정지 시 저장합니다. 세계 상태와 대기 중인 사건을 같은 DB 트랜잭션으로 확정합니다. 살아 있는 개체는 최신 두 신경 파일을 유지하고 사망 개체는 마지막 상태를 보존합니다. 비정상 종료 때에는 마지막 체크포인트 이후 최대 24턴이 되돌아갈 수 있습니다.

개체의 막전위·발화·학습 가중치·세계·난수 상태는 재시작 후 복원되며 세계는 일시정지로 시작합니다. 관측실의 별도 원본 시험 시뮬레이션은 재시작 시 초기화됩니다. 공용 관측 내보내기는 전체 개체의 재개용 백업이 아닙니다. 백업은 앱을 멈추고 `.data` 및 사용하는 PostgreSQL DB를 함께 보관하세요.

### PostgreSQL 사용

설정이 없으면 SQLite로 독립 실행합니다. PostgreSQL 17이 로컬 5432 포트에서 실행 중이면 앱을 닫고 **Configure PostgreSQL.cmd**를 실행하세요. 기존 `postgres` 관리자 비밀번호는 숨김 입력만 받으며 저장하지 않습니다. 전용 DB `neurons`와 제한된 로그인 `neurons`를 생성하고, 앱 계정 연결 정보를 `.runtime/database.json`에 현재 Windows 계정용 DPAPI로 암호화해 저장합니다. 기존 계정의 비밀번호는 변경하지 않습니다.

기존 SQLite 세계가 있고 PostgreSQL이 비어 있으면 같은 개체 ID로 복사하며 원본 파일을 남깁니다. 이미 PostgreSQL에 세계가 있으면 그 세계를 사용합니다. 구성된 PostgreSQL 연결에 실패하면 오류를 표시하며 새 SQLite 세계로 몰래 바꾸지 않습니다. DB에는 개체 상태·행동·자료 복습 사건이 저장되고, 큰 신경 배열과 텍스트 기억 DB는 위 로컬 파일에 남습니다. 모든 신경 접촉을 매 프레임 SQL로 계산하는 구조가 아닙니다. 개발 환경에서는 `NEURONS_DATABASE_URL` 환경변수로 연결을 지정할 수도 있습니다.

연결 설정, 모델, 사용자 기억과 체크포인트는 Git·배포 파일에 포함하지 않습니다.
